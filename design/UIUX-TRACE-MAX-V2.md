## Creative thesis

ShieldRate is not a SaaS dashboard with privacy copy. It is a **private verification bureau** whose core visual object is a trust instrument: a scoped proof receipt that makes requested / proven / hidden information legible at a glance.

## TRACE layers activated

- Aesthetic lineage: institutional verification documents, security paper, audit dossiers, annual-report editorial systems.
- Mechanism layer: receipt register, operator dossier, status rails, disclosure bands.
- Motion grammar: dry state transitions, receipt lift, ordered evidence gates, reduced-motion parity.
- Anti-slop gate: no dark navy shell, neon gradients, glass cards, shield hero, decorative 3D blob or fake-live theater.
- Judge hierarchy: product thesis, exact trust mode, privacy boundary and proof object above the fold.

Primary browser favicon is the new SVG trust mark. The manifest uses the same canonical icon.
